Normal GPS systems rely on satellite signals to calculate the precise position and velocity of the subject. 
When the GPS signal drops, which often happens in dense urban canyons, underground locations and inside deep tunnels, the GPS is unable to locate the subject.

The aim of this project is to try and solve the issue of GPS outage (or rather a workaround the issue of GPS outage), by using a completely different set of technology to temporarily replace the GPS connectivity and help guide users during signal drops. The technology is called Inertial Navigation System. This technology is already in use, where its complemented by expensive commercial grade instruments to measure acceleration and gyro values and calculate coordinates based on those data.

All modern smartphones have, what's called an IMU - The inertial measurement unit. An electronic device that measures the phones acceleration, angular velocity and orientation. But most phones have low grade IMUs that along with accel and gyro values also measure the noise associated with driving on Indian roads.
